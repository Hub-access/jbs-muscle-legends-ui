## 每一页对应旧版什么

- **主要**：目标次数（0 为无限）、自动重生、自动锻炼、自动轮盘。
- **传送**：大厅、小岛、冰霜健身房、神话健身房、永恒健身房、传奇健身房、肌肉之王健身房、丛林健身房、工业健身房、超载健身房、无转盘岛、熔岩争斗、沙漠争斗、海滩争斗。旧代码坐标保存在清单中，没有更改。
- **宠物**：宠物商店购买、选择宠物/光环、刷新宠物列表、购买一次、自动购买。49 项来自旧版的兜底列表，不代表已经核实当前游戏库存；原生界面优先读取游戏商店目录。
- **Boss**：自动打Boss。目标由旧版业务寻找，没有额外编造固定 Boss 名单。
- **换包重生**：换包重生、快速锻炼、蛋白蛋、自动吃蛋、送蛋目标、送蛋数量（0 为全部）、送蛋。
- **设置**：这次新增的界面设置，可切换完整效果/减少动态。

右侧五个开关是上述功能的快捷入口，与对应页面共用状态：自动购买、自动打Boss、换包重生、快速锻炼、自动吃蛋。

## 几个英文词怎样理解

- `id` 是代码内部的稳定标识，例如 `petbuy`；`title` / `label` 是画面显示的“自动购买”。改中文文案通常不必改 id。
- `selected` 是开关选择；`choices` 是下拉选择；`parameters` 是输入的次数/数量。
- `callback` 是点击后要执行的函数；`adapter` 把界面动作转交给原有游戏功能。
- `scope` 是资源清理箱；所有本界面的事件连接会登记在这里。
- `Tween` 是属性渐变动画；`context.Cancelled` 是停止标记，异步任务等待返回后仍需检查。
- 坐标 `x/y/w/h` 表示左边距离、上边距离、宽、高，以 1672 × 941 为桌面基准；默认保持字号并响应窗口重排，中栏允许滚动，舒适模式可缩至 90%。

一次点击的路线是：**View / LegacyPages → Controller → BusinessAdapter → BusinessBindings → 你的游戏模块**。动画和重绘不会自行启动游戏任务。

## 动态预览与 Roblox 的区别

Chrome 地址是 <http://127.0.0.1:8775/>。可以切页、开关、输入、模拟传送与购买、开始/停止、隐藏/恢复、拖动窗口。所有结果明确写着“演示”，没有执行 Roblox 操作。送蛋目标必须来自游戏中的其他玩家，浏览器里保留空列表和不可用的送蛋按钮。

原生 Luau 的控件、状态和动画已经实现；**游戏业务仍待接线、图片仍待上传资源 ID，尚未经过 Roblox Studio 实机验证**。有名字不等于功能已接通，所以未接线的游戏按钮显示“未接入”。本次没有修改旧版的 Remote、循环、频率或坐标。

## 修改后如何更新发布文件

在原生工程目录运行：

```sh
python3 tools/sync_catalog.py  # 如果改了共用名称清单，先同步两个界面
python3 tools/build.py         # 从 src 重新生成单文件、模型和本地场景
```

浏览器开发服务运行时会自动更新。`src/catalog.js`、`src/LegacyCatalog.lua`、`src/AssetData.lua` 和单文件发布入口都属于生成文件，注释中会标出来源；请先改对应原始清单或模块，避免下次生成覆盖修改。

进一步逐项核对请看 [旧版控件对照表.md](旧版控件对照表.md)。
